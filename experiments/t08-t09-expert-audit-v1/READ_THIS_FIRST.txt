WHAT EACH AUDITOR DOES

1. Read the interface's Instructions and four-point guide.
2. Complete fictional practice with the facilitator before formal scoring.
3. Review all 60 query pairs / 120 responses independently.
4. Give separate relevance and faithfulness scores of 1-4, or mark an affected
   dimension unscorable with a reason. This is missing data, not score 5.
5. Add evidence notes and error flags where needed. Both responses may tie.
6. Download a JSON backup at breaks. Autosave alone is not a durable backup.
7. Export final JSON and final CSV; return both to the researcher.

The JSON is the canonical returned data. CSV escapes formula-like notes for
spreadsheet safety. Original note text remains in JSON.
Each expert reviews all 120 responses; do not split the 120 among three people.
Three complete response sets yield 360 review records, up to 720 ordinal scores.
Unscorable dimensions must be reported as missing, never zero or a fifth score.

BLINDING AND SOURCE LIMITS

The distribution packets contain no A/B key, normalizer diagnostics, RAGAS scores,
reference-answer target, original query IDs or ranking scores. Answer content and
retrieved passages are unedited and may still provide indirect identity clues.
Keep the mapping custodian separate from the blinded facilitator and raters.
Researchers with access to the existing public T07 archive cannot be assumed
blind; document actual access instead of asserting absolute double blinding.

The common PDF links follow the original source annotations, including cases
whose chunk IDs could not transfer. They are starting locations, not a new
certification of reference answers. Full official PDFs are supplied so raters
can inspect complete tables and adjacent pages. They should flag source conflicts
and cite any extra pages, rather than substituting assumptions or memory.
Each response's actual retrieved passages are shown separately and verbatim.
Normalized queries, reference answers and full original records remain archived
privately for reproducibility; they are withheld from the rater view to reduce
identity clues and target-answer anchoring.
