What is complete
The authoritative Thesis Tracker defines T06 as Code Automated Evaluation Harness Loop (Hit Rate, MRR, RAGAS), with a Python batch harness supporting paired runs. The repository now implements and exercises that deliverable: archived paired A/B/C development interactions; unchanged-query Hit/MRR scoring; offline RAGAS calls; versioned judge prompts; source/context/answer preservation; metric-specific denominators; explicit clarifications, incomplete generation, nulls and format errors; and reproducible validation.

The original evaluator remains the default for legacy reproduction. A separated-evidence evaluator is available explicitly with --context-precision-v2. It delegates ranked average precision to installed RAGAS 0.1.5 and allows one audited format-only retry. A valid wrong judgment is never retried to improve agreement. Remaining invalid responses stay missing rather than becoming zero scores. This evaluator runs offline and does not filter or rewrite app responses.

Evidence
21 focused unit tests passed, including four tests of the RAGAS adapter, numerical calculation, missing-score behavior and bounded retry policy.
The versioned template was tested on all 60 predeclared source controls across five offices and three languages. After one format-only retry for invalid outputs, 59/60 are valid and 55/60 agree with declared labels. Four false positives and one invalid output remain documented. This is adaptive development calibration, not independent expert validation.
A real batch RAGAS integration run on SCENARIO-BFP-002-taglish returned Context Precision 0.0 for the unchanged wrong-context archive. The old score was not overwritten. This is an integration regression check, not a new full comparison.

The revised evaluator has not yet rescored the complete 90-query grids. No claim that the earlier numeric objective improvements remain valid is made.
