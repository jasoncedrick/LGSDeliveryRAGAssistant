Independent expert audit

Instructions and four-point scoring guide

Read the original question, consult the official source, then score each response independently. Equal scores are allowed. Work independently and do not try to identify the systems.

Answer Relevance

  1. Does not address the inquiry or answers a different question.
  2. Addresses part of the inquiry but misses the primary procedural need.
  3. Addresses the main inquiry with limited minor omissions.
  4. Directly and comprehensively addresses all parts of the inquiry.

Factual Faithfulness

  1. The main answer is unsupported or contradicts the official Citizens’ Charter.
  2. Contains supported claims but includes a major error in a fee, requirement, or office.
  3. Main claims are supported, with minor imprecisions that do not alter the legal procedure.
  4. All factual claims are fully supported and traceable to official source documents.

Evidence: Common source links are starting pages from the original study annotations; they are not certified reference answers. Open the full PDF and inspect tables and adjoining pages when needed. Each response also shows exactly the passages available to that system. Judge factual faithfulness against the official charter; record separately when a true claim was absent from the retrieved passages. Record any additional source pages you consult.

Special cases: Score clarification or abstention by how well it addresses the inquiry. Do not award factual faithfulness 4 solely because there is no factual claim: mark that dimension unscorable with a reason. For blank output, relevance is 1 and faithfulness is unscorable. For incomplete text, score what is present and flag the omission. If a source conflict prevents a judgment, mark only the affected dimension unscorable and explain. Unscorable is missing data, not a fifth score. Do not replace printed ambiguous fees with assumed values.

Saving: Changes autosave in this browser when storage is available. Download a JSON backup at every break; keep it outside the packet folder. Import it to resume on another device. Final export requires a score or justified unscorable mark for every dimension. No name is requested; use only the assigned rater code.
